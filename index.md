# Dusty Cook — Computer Science ePortfolio

## Professional Self-Assessment

Completing the Computer Science program and developing my ePortfolio have helped me better understand my strengths as a software developer and clarify the professional direction I want to pursue. Throughout the program, I have worked with various programming languages, development environments, database technologies, testing frameworks, and software architectures. These experiences have enhanced my ability to systematically approach technical problems, evaluate multiple solutions, and develop applications that balance functionality, maintainability, security, and user needs. My long-term goal is to work in software engineering and full-stack application development, where I can continue building scalable applications and eventually develop my own software products.

My coursework has also shown me that successful computer science professionals require more than programming skills. Collaboration and communication are essential because software is typically created for users, clients, managers, and other developers, each with different technical backgrounds and priorities. Throughout the program, I have practiced communicating technical decisions through project documentation, code reviews, written analyses, presentations, and software demonstrations. The CS 499 code review significantly strengthened this skill, requiring me to explain existing functionality, identify opportunities for improvement, and describe planned enhancements in a way that could be understood by both technical and non-technical audiences.

My technical coursework has provided me with experience in several major areas of computer science. In software engineering, I have designed full-stack applications, worked with modular architectures, utilized version control, debugged complex problems, and improved existing code through refactoring and testing. My work in CS 320 deepened my understanding of automated testing and software quality, while CS 330 offered experience in creating and debugging an interactive OpenGL application. Courses on algorithms and data structures reinforced the importance of selecting appropriate structures and evaluating trade-offs between efficiency, complexity, and maintainability. Database coursework equipped me with experience using MongoDB, Mongoose, SQL concepts, schema design, validation, and full-stack data integration. Security-focused coursework further strengthened my ability to think about software from an adversarial perspective by considering authentication, input validation, data exposure, secure coding practices, and potential vulnerabilities.

The ePortfolio has allowed me to integrate these skills rather than view them as separate areas. Enhancing an existing application required me to consider how changes to one part of the system could affect the user interface, application logic, database, performance, and security of the entire solution. This experience reflects the kind of work I expect to encounter as a professional software engineer, where requirements change and existing systems must be improved without disrupting current functionality.

The artifacts included in my ePortfolio demonstrate this progression through three enhancements to the Travlr Getaways full-stack application. Using the same application across the three enhancement categories allowed me to demonstrate how software engineering, algorithms and data structures, and database development work together within a complete system.

Together, these enhancements demonstrate the progression of Travlr Getaways from an academic full-stack application into a more complete and realistic software solution. The enhancements required me to consider relationships between the Angular frontend, Express and Node.js backend, application logic, MongoDB database, and security controls rather than treating each component independently.

The completed ePortfolio represents both my technical development and my growth as a computer science professional. The original artifact establishes a baseline of my earlier abilities, while the enhanced versions provide measurable evidence of how I can analyze existing software, identify areas for improvement, implement more advanced solutions, and evaluate the results. Combined with my code review and enhancement narratives, these artifacts demonstrate my ability to communicate technical decisions, apply computer science principles to practical problems, and continually improve an existing system.

- Schema design and validation
